# 📚 E-Learning App

Welcome to **E-Learning App**! 🎓✨

This application is designed to provide an interactive and user-friendly online learning experience. With a structured course system, quizzes, and progress tracking, E-Learning App helps users enhance their knowledge efficiently.

---

## 🚀 Key Features

✅ **Course Management** - Create, update, and manage courses easily.
✅ **Quizzes & Assessments** - Test learners’ understanding with interactive quizzes.
✅ **Progress Tracking** - Monitor student progress in real time.
✅ **User Role Management** - Different roles for admins and students.

---

## 🛠️ Technologies Used

- **Laravel 10** (Backend Framework)
- **Bootstrap** (Responsive UI Design)
- **JavaScript & jQuery** (Dynamic Interactions)
- **MySQL** (Database)

---

## 📌 Installation

Follow these steps to set up the project locally:

```bash
# Clone repository
git clone https://github.com/Suekko28/e-learning-app.git

# Navigate to the project directory
cd e-learning-app

# Install dependencies
composer install
npm install

# Create .env file
cp .env.example .env

# Configure database settings in .env

# Generate application key
php artisan key:generate

# Run database migrations
php artisan migrate --seed

# Start the application
php artisan serve
```

Access the application via **http://localhost:8000**.
